## Deskripsi Project
Project ini merupakan aplikasi web sederhana untuk mengelola data kategori dan produk menggunakan PHP dan MySQL.

## Database
Nama database: `web1_pertemuan09`

## Tabel Database
1. Kategori
   - id_kategori
   - nama_kategori

2. Produk
   - id_produk
   - id_kategori
   - nama_produk
   - harga
   - stok

## Fitur
- Menampilkan data kategori dan produk.
- Menambahkan data kategori dan produk.
- Mengedit data kategori dan produk.
- Menghapus data kategori dan produk.

## Teknologi
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Cara Menjalankan
1. Simpan folder project di dalam `htdocs`.
2. Jalankan Apache dan MySQL melalui XAMPP.
3. Import database melalui phpMyAdmin.
4. Buka browser.
5. Akses `http://localhost/web1_pertemuan09/`.
